## 1. 核心概念

### 1.1 什么是Match-3 Pattern

Match-3 Pattern（三消Pattern）是指在N×M的棋盘上，相同类型的游戏元素（如宝石、方块）按照特定几何形状排列所形成的可消除结构。Pattern识别是三消游戏AI、自动化测试和数据合成训练的核心基础能力。

### 1.2 Pattern优先级规则

当棋盘上的连续相同元素同时满足多种Pattern定义时，需按以下优先级进行唯一化分配：

**优先级顺序（从高到低）**：

```
CROSS > T > L > H5/V5 > H4/V4 > H3/V3 > NONE
```

> **设计原理**：复杂Pattern（含交叉结构）优先于简单直线型，长链优先于短链。该规则确保黄金标准标注的唯一性和确定性。

### 1.3 消除判定逻辑

- **连通性判定**：相邻（上下左右，不含对角线）的相同类型元素构成连通区域
- **最小消除单元**：至少3个相同元素构成的连通结构
- **重叠处理**：一个格点只能属于一个Pattern，按优先级分配
- **边界条件**：棋盘边界不延展，Pattern不可跨越边界

## 2. PatternType枚举定义

### 2.1 枚举值一览

| 枚举值 | 名称 | 几何描述 | 最小元素数 |
|--------|------|----------|-----------|
| `NONE` | 无Pattern | 不参与任何消除的独立格点 | — |
| `H3` | 横向三连 | 3个相同元素水平连续排列 | 3 |
| `H4` | 横向四连 | 4个相同元素水平连续排列 | 4 |
| `H5` | 横向五连 | 5个相同元素水平连续排列 | 5 |
| `V3` | 纵向三连 | 3个相同元素垂直连续排列 | 3 |
| `V4` | 纵向四连 | 4个相同元素垂直连续排列 | 4 |
| `V5` | 纵向五连 | 5个相同元素垂直连续排列 | 5 |
| `L` | L型 | 横向3连 + 纵向3连，共享角点（拐角处） | 5 |
| `T` | T型 | 横向3连 + 纵向3连，共享中心点（T交叉处） | 5 |
| `CROSS` | 十字型 | 横向3连 + 纵向3连，中心交叉（+形状） | 5 |

### 2.2 几何特征详解

```
H3:  ○ ○ ○           V3:  ○
                         ○
                         ○

H4:  ○ ○ ○ ○         V4:  ○
                         ○
                         ○
                         ○

H5:  ○ ○ ○ ○ ○       V5:  ○
                         ○
                         ○
                         ○
                         ○

L型（左下拐角）:        T型（向下）:          CROSS（十字）:
     ○                     ○ ○ ○                . ○ .
     ○                       ○                  ○ ○ ○
     ○ ○ ○                   ○                  . ○ .
```

> **注意**：L型有4种旋转方向（左上、右上、左下、右下）；T型有4种方向（T上、T下、T左、T右）；CROSS方向唯一。

## 3. PatternDetector检测器规范

### 3.1 直线型Pattern检测

**横向检测（H3/H4/H5）**：
- 逐行扫描棋盘，查找连续相同元素的最大水平线段
- 线段长度≥3时标记为对应H型Pattern
- 长度≥5的线段优先标记为H5（而非多个H3）

**纵向检测（V3/V4/V5）**：
- 逐列扫描棋盘，查找连续相同元素的最大垂直线段
- 线段长度≥3时标记为对应V型Pattern
- 长度≥5的线段优先标记为V5

### 3.2 L型Pattern检测

**判定条件**：
- 存在一个格点 `(r, c)` 同时满足：
  - 从 `(r, c)` 出发的水平方向（左或右）存在至少2个连续相同元素（含自身共3个）
  - 从 `(r, c)` 出发的垂直方向（上或下）存在至少2个连续相同元素（含自身共3个）
- 该格点为L型的**拐角点（corner）**
- 总元素数 = 5（拐角点被共享，水平2个新 + 垂直2个新）

### 3.3 T型Pattern检测

**判定条件**：
- 存在一个中心格点 `(r, c)` 同时满足：
  - 水平方向存在至少3个连续相同元素，且 `(r, c)` 为该水平线段的**中心点**
  - 垂直方向存在至少3个连续相同元素，且 `(r, c)` 为该垂直线段的**端点或中心**
- 中心点为T型的**交叉点**
- 总元素数 = 5（中心共享，水平各1新 + 垂直2新）

### 3.4 十字型Pattern（CROSS）检测

**判定条件**：
- 存在一个中心格点 `(r, c)` 同时满足：
  - 水平方向恰好3个连续相同元素，`(r, c)` 为中心
  - 垂直方向恰好3个连续相同元素，`(r, c)` 为中心
- 形成标准的 `+` 形状
- 总元素数 = 5（中心共享，上下左右各1个）

### 3.5 格点Pattern优先级分配规则

```
输入: board (H × W 的二维类型数组)
输出: pattern_mask (H × W 的 PatternType 数组)

步骤:
1. 初始化所有格点为 NONE
2. 检测并标记所有 CROSS Pattern（最高优先级）
3. 检测并标记所有 T Pattern（跳过已被标记的格点）
4. 检测并标记所有 L Pattern（跳过已被标记的格点）
5. 检测并标记所有 H5/V5 Pattern（跳过已被标记的格点）
6. 检测并标记所有 H4/V4 Pattern（跳过已被标记的格点）
7. 检测并标记所有 H3/V3 Pattern（跳过已被标记的格点）
8. 返回 pattern_mask
```

## 4. 优先级系统

### 4.1 优先级排序原理

| 优先级 | Pattern | 原因 |
|--------|---------|------|
| 7 (最高) | CROSS | 同时含水平和垂直交叉，结构最复杂 |
| 6 | T | 含交叉结构，比L多一个延展方向 |
| 5 | L | 含拐角结构，比直线复杂 |
| 4 | H5 / V5 | 长链含更多消除元素 |
| 3 | H4 / V4 | 中等长度链 |
| 2 | H3 / V3 | 基础消除单元 |
| 1 (最低) | NONE | 无消除结构 |

### 4.2 冲突解决示例

```
棋盘片段（同类型元素用 X 表示）:

  0 1 2 3 4
0 . X X X .
1 . . X . .
2 . . X . .

中心点 (0,2) 同时满足 H3（第0行）和 V3（第2列）。
根据优先级，该结构应判定为 T型（T向下），而非两个独立的H3/V3。
```

## 6. 使用场景与最佳实践

### 6.1 适用场景

| 场景 | 说明 |
|------|------|
| **训练数据合成** | 作为程序化标注引擎，为生成棋盘生成黄金标准mask |
| **模型评估** | 计算模型预测mask与黄金标准的IoU/Acc |
| **游戏规则验证** | 验证游戏引擎消除逻辑的正确性 |
| **EDA分析** | 统计棋盘中各类Pattern的分布频率 |

### 6.2 最佳实践

1. **检测顺序**：严格遵守 CROSS → T → L → H5/V5 → H4/V4 → H3/V3 的顺序，避免覆盖
2. **类型一致性**：检测前确保board数组值域在 `[0, num_types)` 内
3. **边界检查**：所有Pattern检测均需验证棋盘边界，不可越界访问
4. **性能优化**：大规模棋盘建议分块检测，或使用NumPy向量化操作替代逐格点遍历
5. **缓存复用**：对于静态棋盘，检测结果应缓存避免重复计算
